DayCount Changelog
==================

1.6.1-NeoForge-mc1.21.11
------------------------
New
 - German translation
 - Optional background box behind the day counter (isBoxEnabled, boxColorWithTransparency)
 - Option to format the day number with the system's number format, e.g. 1,000 (useLocaleFormatting)
Fixes
 - Invalid colors in the config no longer crash the game, the default color is used instead
 - Colors with 6 digits (RRGGBB, e.g. FFFFFF) are now shown fully opaque instead of invisible; # or 0x in front of a color is accepted
 - Changes to the text color and to dayCountEnabled in the config now apply without a restart
 - The day counter now hides together with the rest of the HUD when pressing F1
 - The key binding category in the controls screen now shows its name instead of a raw translation key
